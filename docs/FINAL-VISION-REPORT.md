# 最终愿景审计与优化交付

日期：2026-09-08。仓库基线：`74d8925d8afc332e62cb18de5bb35e40df528003`。

## Executive Verdict：MOSTLY

项目已呈现为离线、黑白、自由创造与 AI 观战的小型游戏，底层具有真实的组合深度。此次修复了一个可让合法自定义行动中断对战的 AI 错误、反击估值错误、一个正式预设的进攻自锁，以及手机导航与观战信息缺失。没有改写生成器或统一战斗规则，没有追求公平胜率。

还不能给出无保留的 YES：通用 AI 是当前状态效用估计，缺乏多回合规划；长续航局仍很多；数值知识的广度大于语义回归测试的广度；卡图依然是程序化占位级插画。

## Product Vision

| 原则 | 结论 | 依据 |
|---|---|---|
| Simple Outside | PASS | 默认选卡/生成/自动观战；高级字段折叠；手机一屏可见双方 HP 与资源 |
| Deep Inside | PASS | 复合伤害、条件、触发、资源、状态消费、成长/疲劳真实参与战斗 |
| Classless | PASS | v4 连续预算分配，生成后才做行为描述；没有改动职业/生成路径 |
| AI spectator | PARTIAL | 自动对战、暂停、单步、速度和原子帧有效；长期规划仍有限 |
| No metagame | PASS | 没有经济、养成、奖励、排位、解锁或服务端依赖 |

## 修复清单与严重度

| 严重度 | 实际问题 | 最小修复与证明 |
|---|---|---|
| P0 | canonical AI 遇到合法 `REPEAT_INDEX` 公式抛出未知变量，无法选择行动 | 每个 repeat 子效果传入正确下标，次数与引擎一致；回归先复现异常后通过，并检查评估不改战斗实体 |
| P1 | 百科无返回按钮；旧浏览器测试通过删除 DOM 绕过 | 返回、Escape、浏览器 Back、滚动解锁、焦点恢复/圈定；测试改用实际控件 |
| P1 | 深渊在指定对局中69回合零生命伤害，半血输出门槛被盾/被动回复自锁 | 仅血性猛击从 `HP_PCT < .5` 改为 `< 1`，保留受伤后反击、侵蚀半血门槛、自伤/伤害/冷却/等级/稀有度；同种子37回合、689生命伤害 |
| P2 | 连续子效果隔离公式上下文后，预测状态层数没有持久保留 | 独立保存预测层数/持续时间；满层增益只计一次，且不修改真实战斗状态 |
| P2 | 自带受击反击被错误扣到无自伤的主动攻击上 | 仅在反噬存在时估计其引发的自身反击成本；无自伤前后攻击评分相同 |
| P2 | 旧卡改名/技能或战力权重改变后 metadata 缓存可能失效不完整 | 统一卡牌展示签名覆盖数据和当前权重；回归验证搜索与 canonical BP 一致 |
| P2 | 手机观战没有显示资源/类型护符，卡图占用高度使双方难以同屏 | 从当前展示快照读取资源/护符；压缩移动端战斗卡图，浮字避开 HP；原子 HP 与资源读数验证 |
| P2 | 筛选区挤占选卡首屏，12档稀有度样式名没有实际边框区别 | 搜索/稀有度保留直接入口，等级/特点/排序折叠；用黑白线宽、双线与徽章区分 |
| P2 | 搜索输入失焦时 change 重绘结果，可能吞掉点击 | 输入与分类事件分别处理，移除 pointerup 补丁；实际触屏点击复验 |
| P2 | 详情返回后等级控件与实际筛选状态不一致 | 同步恢复等级选项；增加带筛选往返详情回归 |
| P2 | onboarding 未区分 engine 旧 AI 与 canonical AI；部分知识过度承诺 | 明确 `src/ai.js` 入口；修正 RAMP 的 AI 说明与 EVA 公式上下文；自动生成参考文档 |

## Numerical Depth / Generator / Engine

- 60预设 + 10,000个v4样本：111参数、18效果、27条件、8目标、29事件、43公式变量、14公式函数、8伤害类型；未文档化活跃字段为0。
- 10,000个样本有10,000个机制指纹，重复率0；行动数2–6，生成覆盖17种效果（不含旧兼容 energy 别名）、8种伤害类型；3443张无直接伤害行动，354张多治疗，761张多护盾，1643张多状态。
- 时间分布：3833疲劳、2746成长、1622混合、1799稳定；波动分布低3791、中3279、高2930。以上是结构与采样证据，不能单独证明每张卡都好玩。
- 六条独立语义扰动 ATK / LIFESTEAL / VOLATILITY / RAMP / FATIGUE / HEAL_POWER 全通过。合法 REPEAT_INDEX 原有执行能力真实存在，本轮修的是AI理解它的能力。
- 未发现此次检查范围内 Generator 写入而引擎完全不读取的已确认死字段。**不将 coverage=0缺口等同于111项逐项语义证明**；部分旧知识条目的调高/调低、例子、读取方仍稀疏。
- canonical PRNG、Acorn restricted evaluator、v1/v2/v3固定输出与旧 replay 路径保留。唯一预设数据变更不改生成输出；历史自包含 replay 仍携带其原始内容。

## AI 与长局

当前 canonical AI 覆盖伤害、有效治疗、盾/护符相关性、状态与消费、事件、资源需求/上限、冷却、优先级、吸血与反噬；从 Stats/Actions/状态决策，不读取 Behavior Tags。

本轮解决了下标异常与虚假自伤扣分；另将预测状态从公式局部上下文分离，避免连续增益对已满层状态重复计分（回归从48修正为16）。仍有近似：伤害附带吸血/反噬用简化 EV，状态、触发链、先后效果状态推演与长线价值不是完整多回合搜索；更高成长数值并不意味着AI懂得主动等待。没有加入卡牌ID特判。

3000场最终生成卡审计：中位5回合，P90=61，P95=69，最长88；超过40回合为26.17%，回合上限命中0，平局1.13%（包括双亡）。基线长局26.5%。这种微小改善不能称为解决拖沓；某些续航/无伤害构筑依然主要靠 Battle Wear 收束。

## BattlePower

修改后的72张生成卡校准：1256个有效比较对，Spearman **0.765**，配对排序一致率 **80.6%**；此前0.765/80.7%。修正实际AI行为后指标与基线接近，接受真实数据，没有为了BP反向改变卡牌。

BP继续是静态泛用强度参考。复杂条件的可达性、对手克制、反击链、资源时序只能近似；某些随机样本的相邻稀有度中位数可以倒挂。同seed/等级方向由现有梯度测试保护。深渊修改后canonical BP仍2813，这也直观说明该模型不能充分辨认启动条件改善。

## Presets 与 Human-like Review

60张、12×5、curationVersion=2保持；只有深渊一处启动条件改变，59张卡数据完全不动。420场全面板审计0结构错误、0近重复；未使用行动保留为情境诊断，不能把6个对手中没用过直接判死技能。

真实Chrome手机viewport中通过实际选卡、打开详情、点击开战和4×播放观察15场，30张不同官方卡、12档稀有度。全部播放到最终帧，不是直接调用模拟器跳过表现层。长局含50、37、35、28回合；也包含明显强度差导致的一回合击倒。

逐场记录、行动频次、事件类型与定时屏幕文本见 `qa/human-like-review.json`；复现脚本 `qa/browser-vision.js`（三独立浏览器上下文并行播放，未使用子Agent）。截图是自动采集后由本次Agent实际打开检查，**不冒充真人玩家测试**。

观感：赤隼/曜甲的50回合多行动、状态消费与防御变化可区分于纯重复；绝刃/渊影有治疗和姿态切换；不朽/湮灭有较丰富行动轮转；深渊原本反复盾/护符且不出手是明确失败样本，修后会使用血性猛击。短局体现强度差，不强改成公平。想继续对比的对象是这些有时间曲线/消费联动的卡，而非占位图本身。

## Mobile UX / Visual Design / Knowledge

390×844：首页左右选择和开始入口可见；选卡首屏完整展示一张卡主体；详情默认隐藏公式；百科可返回。手机战斗双方卡、HP、盾、资源、状态与事件清楚分层，浮字不盖住血条。保留lazy render（12张一批）、搜索/交叉筛选、排序、选左右和原子时间线。

黑白极简已达到干净、可继续点选的小游戏水平；C与XS典藏有明显框线/徽章差别。卡图仍是简单程序化角色，形状变化有限，不能评为成熟角色插画；没有添加外部素材或新依赖。字体/按钮遵循既有系统，不做框架迁移。

现有玩法说明已覆盖快速开始、rarity/level/BP、核心数值、行动、随机、成长疲劳、AI、创作与高BP可能输，无须增加强制教程。详细数值改为中文名优先、保留标识与知识入口。一般玩家可入门，新Agent可通过AGENTS→registry→生成参考→相关测试快速定位；更高级条目的教材化仍有余地。

## Architecture / Performance

强项：数据组件注册、受限公式、canonical PRNG、内容/replay自包含、原子快照。弱点：app.js集中渲染与事件，engine保留旧planner、canonical另置ai.js；目前保留兼容边界比大拆更安全。只修真实缓存/导航问题并补清晰地图。

本机Chrome的390×844仿真单次测量：初始导航 **92.9ms**、picker点击到结果 **79ms**、开战 **13ms**。4×带事件帧主要152–157ms，暂停/步进造成的等待不作为渲染卡顿。测试时另有审计进程，数据不等同于真实手机性能，也不是统计基准。无主线程Monte Carlo渲染；未安装依赖。目标Browser skill不在会话技能中，按测试技能回退现有Playwright+已安装Chrome。
